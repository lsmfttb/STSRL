# T111: Configured-Search-Domain N=2 Support Re-entry

Artifact Eligibility Required: true

## Objective

Determine whether the exact T110 configuration-aware native bridge restores a sufficiently large **configured Search-domain** support cohort for the original T101 natural Battle-start population, without pretending that legal public actions intentionally excluded from the frozen Search configuration have Search values.

T111 is a bounded support/admission re-entry only. It is not a particle-count convergence experiment, not a public-fidelity diagnosis, not a projection-parity diagnosis, and not a controller-promotion task.

The falsifiable question is:

> under the original T101 deterministic source population/order, exact current native pin, N=2, Search-v2@400, and `include_potions=false`, can each A/B/C stratum produce the first 8 states whose **configured Search decision domain** is structurally valid and has finite searched values, while configuration-excluded public potion actions remain visible/auditable but unvalued?

A successful T111 establishes only a 24-state support cohort for a later convergence re-entry.

## Configured Search-Domain Scientific Contract

### 1. Full public surface remains authoritative for legality/parity

Every bridge response must preserve the complete ordered public legal-action surface. Configuration-excluded actions are **not removed** from the public surface and are not hidden from retained evidence.

Public projection and ordered public-action parity remain admission requirements.

### 2. Every public occurrence must be classified

Use the accepted native v2 classification only. Each public occurrence must be exactly one of:

- `searched_direct`;
- `searched_mechanical_duplicate_card_occurrence`;
- `search_configuration_excluded`.

Unknown/missing classifications fail closed.

### 3. Configuration exclusion remains narrow

A configuration-excluded occurrence is admissible only if the T110 strict validator proves all accepted conditions, including:

- battle action kind is `potion` or `potion_discard`;
- public input state is `PLAYER_NORMAL`;
- bridge/root `include_potions=false`;
- exclusion reason is `include_potions_false`;
- Search edge/source/mapping mode are null;
- visits are integer zero;
- evaluation sum and mean value are null;
- mapping-row edge/mode/source/edge-occurrence-count are null.

Null by itself never establishes exclusion. Numeric zero never substitutes for an absent value.

### 4. Configured Search decision domain

For T111 scientific admission, the **configured Search decision domain** consists only of public occurrences classified as searched.

Configuration-excluded occurrences:

- remain retained in original public order;
- remain part of legality/parity evidence;
- have no Search-equivalence decision class;
- are excluded from finite-value requirements;
- are excluded from ranking/top-choice/proxy calculations;
- may not be assigned, imputed, inherited, or synthesized a Search value.

This is a bounded Search-domain claim. It is not a claim that the full legal action domain has values, and it is not a deployable full-action controller contract.

### 5. Searched occurrence requirements

Every searched occurrence must retain T110/T099 strict provenance:

- concrete nonnegative Search edge/source edge;
- valid direct or mechanical-duplicate mapping mode matching classification;
- correct public ordinal and identity;
- finite numeric `evaluation_sum`;
- finite numeric `mean_value`;
- positive visits for a required finite mean;
- no configuration exclusion reason.

Every actual Search root edge must be covered by at least one searched public occurrence. Duplicate mechanically equivalent card occurrences may share one Search edge exactly as before.

### 6. Decision-class partition

For support purposes, Search-equivalence decision classes are formed only from searched occurrences using the accepted native occurrence mapping.

Requirements:

- no Python reimplementation of card mechanical equivalence;
- public duplicate occurrences sharing one accepted source edge form one decision class;
- the searched/excluded classification by public ordinal and the searched decision-class partition must be identical across both N=2 particles for one candidate;
- classification/partition drift fails the candidate closed;
- excluded occurrences never create a singleton class.

A state with only one configured Search decision class may still be admitted, matching T101's prior one-action-state policy. The cohort report must separately count states with at least two configured Search decision classes.

## Support Admission Selector

T111 must re-run the original deterministic selector from the full 413 source population. Historical failure labels may be used for interpretation after execution but must **not** be used to preselect or skip candidates.

For each stratum A, B, and C independently:

1. iterate candidates in the exact original T101 deterministic order;
2. stop that stratum immediately after 8 candidates are admitted;
3. for each attempted candidate, restore the exact accepted Battle-start state with no reseed;
4. verify current-native public projection and ordered public legal-action parity;
5. perform exactly one N=2, Search-v2@400, `include_potions=false`, replicate-0 bridge call;
6. validate the complete T110 v2 bridge/mapping contract;
7. apply the configured Search-domain support contract above;
8. admission may inspect only structural validity and required finiteness, not value magnitude, ranking, Battle outcome, hidden-diversity magnitude, or historical T088 outcome;
9. retain the attempt and a structured admission/exclusion reason.

Do not backfill between strata.

If any stratum exhausts its full source population with fewer than 8 admitted states, terminate `CONFIGURED_SEARCH_DOMAIN_SUPPORT_INSUFFICIENT`.

If all three strata reach 8, terminate `CONFIGURED_SEARCH_DOMAIN_SUPPORT_SUFFICIENT` and retain exactly the first 8 admitted identities per stratum.

The selector must not continue running candidates after a stratum reaches 8 merely to estimate prevalence. T111 is a support gate, not a census.
