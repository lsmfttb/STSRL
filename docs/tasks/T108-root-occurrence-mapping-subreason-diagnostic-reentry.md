## Mapping Subreason Semantics

The seven failure subreasons have only their accepted control-flow meaning:

- `no_public_legal_action_surface`: native mapping reached the existing no-public-legal-action branch;
- `multiple_direct_search_root_matches`: direct Search-root matching produced the accepted multiple-match failure branch;
- `missing_non_card_direct_search_root_match`: a non-card public occurrence had no accepted direct Search-root match;
- `card_not_adjacent_mechanical_duplicate`: the card occurrence could not use the accepted adjacent mechanical-duplicate representative rule;
- `representative_search_root_match_zero`: the selected mechanical-duplicate representative had zero accepted Search-root matches;
- `representative_search_root_match_multiple`: the selected representative had multiple accepted Search-root matches;
- `uncovered_search_root_edge`: mapping reached the accepted Search-root-edge-with-no-public-occurrence coverage failure.

These labels do **not** by themselves establish:

- whether public action identity is wrong;
- whether Search root edge identity is wrong;
- whether duplicate cardinality/multiplicity is wrong;
- whether ordered occurrence indexing is wrong;
- whether Search materialization changed representation incorrectly;
- whether the mechanical-equivalence contract is wrong;
- whether a game-mechanics action type is unsupported;
- whether a public-semantic Search-edge redesign is required.

Those are successor hypotheses to be selected only after the observed census is accepted.
