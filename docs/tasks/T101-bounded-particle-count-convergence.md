# T101: Bounded Particle-Count Convergence and Cost Diagnostic

Artifact Eligibility Required: true

## Objective

Measure whether the accepted T099 public-consistent particle-to-Search capability
produces a numerically and operationally stable **outer particle-integration
proxy** over a bounded natural Battle-start cohort as particle count increases.

T101 asks one falsifiable bounded question:

> with the public state, native source, hidden-future sampler, unguided
> Search-v2@400 continuation, action surface, and cohort fixed, how stable are
> the cross-particle strategy-fusion proxy values and root-decision classes at
> nested particle counts 2, 4, 8, 16, and 32, including independent
> sampler-seed replication and measured Search cost?

This is a convergence-and-cost **diagnostic**. It does not create a deployable
normal-information controller.

For one accepted public information state (I), one public root action
occurrence (a), and public-consistent hidden-future particles (H_j), T101
may compute the offline descriptive quantity:

```text
M_N(I, a) = (1 / N) * sum_j q_full(H_j, a)
```

where every (q_full(H_j,a)) is the accepted T099 per-particle
`full_state_continuation_strategy_fusion_proxy` produced by unchanged
full-state Search v2.

The task must call the resulting aggregate a
`strategy_fusion_mean_proxy` or equivalent. It must **not** call it:

- exact `Q_public(I,a)`;
- executable no-SL continuation value;
- information-set-optimal value;
- exact posterior expectation;
- a Bayesian posterior estimate;
- a deployable action value.

Stability of this proxy is a numerical/economic result only. It does not solve
strategy fusion.

## Particle Counts And Replication

Frozen nested counts:

```text
2 -> 4 -> 8 -> 16 -> 32
```

Formal replication count:

`R = 4` independent sampler replicates per state.

For each state and replicate, derive the sampler seed deterministically from:

```text
SHA256("T101-v1" || selection_identity || replicate_index)
```

using a documented fixed integer conversion that is valid for the native API.

This is ordinary deterministic experiment seeding. It must not inspect,
reverse-engineer, infer, or condition on the game's hidden PRNG state.

For each state/replicate, perform one native T099 bridge call at:

- `particle_start=0`;
- `particle_count=32`;
- `search_simulations=400`;
- `include_potions=false`.

The formal N=2/4/8/16 results must be computed from the ordered prefixes of
that exact N=32 batch. Do not run independent particle sets for different N in
the formal study.

Therefore the complete formal study contains:

`24 states * 4 replicates * 32 particles = 3072 per-particle Search-v2 continuations`.

No N>32 execution is authorized.

## Public Decision Classes And Duplicate Occurrences

mechanically equivalent duplicate card occurrences to one Search edge.

T101 must retain every public occurrence and its T099 mapping.

For decision-stability analysis only, construct a **Search-equivalence decision
class** from the T099 occurrence-equivalence mapping. Public occurrences that
share the same accepted Search source edge/equivalence class count as one
decision class for ranking and top-choice agreement.

Requirements:

- the equivalence partition must be identical across all particles for one
  public state;
- no Python reimplementation of the native mechanical-equivalence predicate;
- no duplicate occurrence may receive extra statistical weight merely because
  several public ordinals map to one Search-equivalent decision;
- per-occurrence rows remain retained for audit/provenance;
- action-class aggregation is analysis only and is never executed as a
  controller.

If the equivalence partition changes across supposedly public-equivalent
particles, fail the state rather than inventing a reconciliation rule.

## Required Convergence Metrics

For each state, replicate, and N in 2/4/8/16/32, compute from the nested prefix:

### Per decision class

- arithmetic mean `strategy_fusion_mean_proxy`;
- sample standard deviation where N >= 2;
- standard error as a descriptive Monte Carlo statistic;
- minimum/maximum proxy value;
- particle support count.

### Decision stability

Define the best decision-class set as all classes tied at the exact maximum
aggregated proxy value. Do not break ties using card order, hidden state, or an
ex-post epsilon.

For each state/replicate/N retain:

- best decision-class set;
- number of decision classes;
- exact agreement of the best set with that replicate's N=32 best set;
- N32-reference proxy opportunity gap:

  ```text
  max_class M_32(class) - max_{class in best_N} M_32(class)
  ```

  where the quantity is explicitly labeled a reference-proxy opportunity gap,
  **not regret**;
- maximum absolute per-class mean drift relative to the same replicate's N=32
  aggregate;
- rank agreement against the same replicate's N=32 class ordering using a
  documented tie-aware statistic when at least two classes exist.

### Across sampler replicates

For each state at N=32 retain:

- four replicate best decision-class sets;
- number of distinct best sets;
- whether all four are exactly identical;
- modal best-set share;
- per-class between-replicate dispersion of N32 proxy means.

The report must distinguish:

- prefix sensitivity inside one particle sequence;
- sampler-seed sensitivity between independent particle sequences.

These are different failure modes.

### Cohort summaries

For every N report, separately for:

- all 24 states;
- A/B/C strata;
- multi-class informative subset:

at minimum:

- best-set agreement with same-replicate N32;
- distribution of reference-proxy opportunity gap;
- distribution of maximum mean drift;
- rank-agreement distribution;
- N32 replicate-unanimity count/fraction;
- hidden-fingerprint diversity distribution, descriptive only.

Use state identity as the independent resampling unit for any bootstrap
interval. If bootstrap confidence intervals are reported, use exactly 20,000
deterministic cluster resamples with seed `101101`, preserving all four
replicates of a sampled state together.

Do not bootstrap individual particles as if they were independent public
states.

## Stability Classification

T101 intentionally avoids an ex-post percentage threshold such as "90% stable".

For each state define N32 reference stability as:

> all four independent N=32 replicates have exactly the same best
> Search-equivalence decision-class set.

If every one of the 24 formal states satisfies that condition, compute the
smallest N in 2/4/8/16/32 for which, for every state and all four replicates,
the best decision-class set equals that state's unanimous N32 reference set.

This produces one strict bounded-cohort diagnostic:

- `n32_reference_unanimous_all_states: true/false`;
- `smallest_uniform_prefix_n: 2|4|8|16|32|null`.

This is intentionally conservative. Failure of uniformity does not prove that
a particle method is unusable; it only prevents T101 from claiming uniform
bounded-cohort decision stability.

Numeric drift, gaps, and rank metrics remain first-class evidence regardless of
this strict classification.

## Terminal Classifications

### `BOUNDED_PARTICLE_PROXY_STABILITY_OBSERVED`

Use only if:

- all scientific/provenance/runtime evidence is complete;
- all 24 states have unanimous N32 best decision-class sets across all four
  sampler replicates;
- `smallest_uniform_prefix_n` is non-null.

The report must name that smallest N and retain the full numeric/cost metrics.

Meaning is strictly:

> on this bounded balanced natural Battle-start cohort, under the exact T101
> sampler and full-state Search-v2@400 proxy semantics, decision-class choice
> was uniformly stable by the reported N relative to the unanimous N32
> replicate reference.

It does not establish convergence to a true public-information value or a
deployable controller.

### `BOUNDED_PARTICLE_PROXY_STABILITY_NOT_ESTABLISHED`

Use when the complete valid study finishes but either:

- at least one state has non-unanimous N32 best decision-class sets across the
  four sampler replicates; or
- no N<=32 provides uniform prefix agreement across the full cohort.

Report exact unstable states, strata, margins/gaps, replicate patterns, and
cost. This is a valid negative result.

Do not automatically scale above 32.

### `SUPPORTED_COHORT_INSUFFICIENT`

Use if the frozen support-admission process cannot produce 8 admissible records
in each A/B/C stratum without changing the contract.

This is a support-domain result, not convergence evidence.

### `OPERATIONALLY_INFEASIBLE`

Use only if the canary proves the frozen formal design cannot be executed under
documented available resource constraints without changing N, R, Search@400,
cohort size, or native semantics.

Do not silently shrink the study and call it formal evidence.

### `INCOMPLETE`

Use for missing/corrupt scientific evidence, failed identity/provenance gates,
partial formal execution, or any other state in which the frozen analysis
cannot be completed validly.

## Successor Meaning
