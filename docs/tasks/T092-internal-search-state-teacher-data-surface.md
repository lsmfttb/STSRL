# T092: Internal Search-State Teacher Data-Surface Gate

## Objective

Determine whether the accepted frozen Battle planner, unguided Search v2 @400,
can expose a **materially larger, leakage-safe, public-input training-data
surface from stable internal Search tree decision states** without changing any
Search decision, allocation, rollout, backup, terminal utility, or Battle
action semantics.

T092 follows T091's accepted result:

- complete root-Q supervision was only `309 / 6,210 = 4.9758%` in T090;
- partial root supervision at `n_min=4` was much denser, but still failed the
  preregistered T091 root-surface gate (`4,074 / 6,210 = 65.6039%` raw
  pair-supported roots; 3,534 leakage-safe deduplicated examples; 44,846
  retained ordered non-tie pairs; median supported/legal fraction `0.25`);
- T091's bounded source audit concluded
  `CURRENT_SEARCH_INTERNAL_SURFACE_FEASIBLE` because Search already reconstructs
  stable internal `PLAYER_NORMAL` / `CARD_SELECT` states and retains child visit
  and evaluation statistics at expanded tree nodes.

T092 therefore asks one bounded question:

> Under exactly the frozen Search-v2@400 controller and exact T087/T090 413-start
> Battle distribution, does a read-only internal-tree telemetry surface yield a
> substantially larger and sufficiently broad set of public-state/action
> preference examples than the accepted T091 root-only surface, while proving
> that enabling telemetry leaves Search semantics unchanged?

This is a **teacher-data-surface generation/measurement task**. It does not train
any student, modify the Search policy, implement a CombatSolver-style solver, or
claim Battle-policy improvement.

## Core Research Boundary

T092 keeps three objects distinct:

```text
Search/controller semantics:
    how frozen Search-v2@400 chooses actions

Teacher-searchable action space:
    actions Search actually enumerates under its frozen no-potion configuration

Public game action space:
    all actions visible/legal to the player, including actions deliberately
    outside the frozen teacher configuration
```

T092 measures only supervision generated by the **teacher-searchable action
space**. A public legal action excluded by the frozen teacher configuration is
reported separately as `teacher_action_space_excluded`; it is never counted as
an unvisited Search action and never enters a Search support denominator.

For T092, **internal means `tree_depth >= 1`**. The Search root at
`tree_depth=0` is not an internal candidate and is excluded from every internal
occurrence count, public-fingerprint/deduplication count, partial-pair count,
action-kind participation count, ambiguity diagnostic, density metric and
viability predicate. The depth-0 root remains part of the existing root
controller evidence used for telemetry OFF/ON semantic parity and exact
T090/T091 root reproduction. This prevents accepted T091 root-only supervision
from being double-counted as incremental internal-surface gain.

The task must not repeat the T090/T091 mistake of turning "every internal node
must have dense child support" into a Search-quality target. Search is allowed
to concentrate its finite budget. Internal-surface viability is judged by the
**absolute, diversity-aware and cost-normalized amount of leakage-safe usable
supervision produced**, not by requiring a high fraction of all expanded nodes
to become training examples.

## Additive Native Telemetry Contract

T092 may add one bounded, opt-in telemetry capability to the native Search
boundary after exact-spec approval.

The capability must be **disabled by default** and must not change Search output
or work when disabled. When enabled it may only copy/read information already
present during or after the frozen search traversal.

The implementation may choose an efficient representation, but the accepted
capability must satisfy all of the following:

1. Search selection, expansion, rollout, backup, evaluation and root-selection
   code paths remain semantically unchanged.
2. No telemetry callback or serializer may consume Search RNG, simulator RNG, or
   mutate the searched `BattleContext`, Search tree, edge statistics, or action
   ordering.
3. A candidate internal state is exportable only when it is a reconstructed,
   nonterminal player-decision state with native input state exactly
   `PLAYER_NORMAL` or `CARD_SELECT` **and `tree_depth >= 1`**.
4. The `tree_depth=0` Search root is never emitted or retained as an internal
   candidate row and never enters internal density/diversity/ambiguity/viability
   accounting. Root evidence remains on the existing root telemetry path used
   for parity and T090/T091 reproduction.
5. Transient ActionQueue execution states, terminal states, rollout-only
   temporary states, and unexpanded tree nodes are not training candidates.
6. Internal path/source identity is provenance metadata only. It is not an
   exact-transposition identity and must not be used as student input.
7. Child visit/evaluation statistics are read from the final Search tree. For a
   child with `visits > 0`, teacher mean is
   `evaluationSum / simulationCount`; zero-visit children remain unknown.
8. Any replay of an action path solely to reconstruct a public projection must
   operate on a private copied state after/beside Search, must not affect Search
   counters or RNG, and its telemetry-extraction transition cost must be
   accounted separately from controller Search cost.
9. No raw `BattleContext`, checkpoint bytes, RNG state, hidden draw order,
   ActionQueue function objects, private monster RNG/future values, or full
   simulator serialization may leave the native/private telemetry boundary.

A task-scoped native implementation commit must descend from publication native
`20a6c2b3a9cea817c988178b814f083ff889853f`. Its exact repository/ref/commit and
source diff must be pinned on the T092 PR before any real canary. A semantic
change outside this additive telemetry boundary requires Planner amendment and
renewed exact-head approval.

## Public Fingerprint And Leakage Boundary

Define one versioned public decision fingerprint over:

```text
(public-tactical-v2 student-visible Battle state,
 ordered teacher-searchable public action identities)
```

The fingerprint must not include source id, split, Search path, hidden simulator
state, child visits/means, terminal outcome, or future-derived fields.

All occurrences inherit the split of their exact T087/T090 source start.
Depth-0 root occurrences are outside this internal fingerprint corpus and must
not participate in internal collision, multiplicity or deduplication counts.

For leakage-safe unique-example counts:

- if one fingerprint appears in more than one split, exclude all occurrences of
  that fingerprint from learning-eligible counts;
- within one split, deterministically retain one canonical occurrence per
  fingerprint and report multiplicity;
- never reassign split after Search statistics are observed.

Repeated public fingerprints must also report teacher disagreement lower bounds:
selected/best-supported action disagreement where defined and pairwise mean-sign
conflicts for repeated supported action pairs. As in T091, these are lower
bounds only; low conflict does not remove the T034 hidden-future warning.

## Internal Partial-Pair Surface

For every stable internal multi-action node with `tree_depth >= 1`, evaluate
support thresholds:

`n_min in {1, 2, 4, 8, 16}`

A teacher-searchable action is supported at threshold `n_min` when:

- the corresponding child exists exactly once;
- child visits are at least `n_min`;
- child mean is finite.

For each unordered pair of supported actions:

- if `abs(mean_i - mean_j) <= 1e-9`, retain a teacher tie diagnostic only;
- otherwise retain one ordered preference pair from larger mean to smaller mean.

No value or preference may be invented for an unvisited or teacher-excluded
action.

`n_min=4` is the primary comparability surface because T091 used the same frozen
threshold at the root. The full sensitivity curve is required, but successor
selection must not cherry-pick another threshold after results are known.

## Internal-Surface Viability Gate

This gate asks whether the **depth>=1 internal surface** is materially more
useful as a training-data source than the accepted root-only surface. It is not
a Search performance metric and does not require a high fraction of all expanded
nodes to be usable. Depth-0 root evidence is excluded from every predicate below.

At primary `n_min=4`, after cross-split fingerprint exclusion and deterministic
within-split deduplication, all of the following must hold:

1. at least `35,340` unique internal decision examples with at least one ordered
   non-tie pair (`10x` the accepted T091 root-only unique-example count);
2. at least `224,230` retained ordered non-tie pairs (`5x` the accepted T091
   root-only retained-pair count);
3. each source group A/B/C contributes at least `5,000` leakage-safe unique
   internal examples;
4. source-group usable-example yield per 1,000 Search simulations for every
   group is at least `50%` of the overall usable-example yield per 1,000 Search
   simulations;
5. for every teacher-searchable branching bucket containing at least `10,000`
   stable internal multi-action occurrences, at least `500` leakage-safe unique
   `n_min=4` examples remain from that bucket;
6. at least `90%` of teacher-searchable public action kinds occurring in at
   least `1,000` internal legal instances participate in at least one retained
   `n_min=4` ordered pair;
7. controller semantic parity and formal root reproduction pass with zero
   mismatches;
8. provenance/public-information boundary validation has zero violations.

Potion/potion-discard or any other action kind excluded by the frozen teacher
configuration is **not** counted in predicates 5-6 or supported/legal
fractions. Its exclusion frequency is reported separately.

The full `n_min` sensitivity curve and telemetry throughput are required context
for interpretation even though `n_min=4` is the frozen promotion surface.

## Information Boundary

The teacher may use privileged/full simulator state internally because this is
training-time Oracle-like Search. The exported candidate student representation
must remain public-only.

Forbidden future student features include, non-exhaustively:

- simulator/checkpoint/RNG bytes;
- draw-pile hidden order or unrevealed future content;
- Search path, depth, source, split, visits, mean values or UCT scores;
- native node/edge pointers or expansion ordinals;
- terminal outcome or future-transition-derived features;
- full simulator/private state identity.

These may exist only as provenance/target metadata where explicitly allowed.

T092 does not solve T034. Repeated-public-state disagreement is only an observed
lower bound on privileged-teacher ambiguity.

## Terminal Classifications

Exactly one primary terminal classification must be recorded.

### `INTERNAL_SEARCH_SURFACE_DENSE_ENOUGH`

All validity, semantic-parity, root-reproduction and internal-surface viability
predicates pass.

Consequence: Planner may publish a **separate internal-state partial-ranking
Battle-student distillation task**. That successor trains a public-only student
and does not integrate it into Search in the same task.

### `INTERNAL_SEARCH_SURFACE_TOO_SPARSE_OR_BIASED`

Telemetry is valid and semantically passive, but one or more internal density,
diversity or source-balance predicates fail.

Consequence: do not weaken the internal-surface thresholds or tune Search to
manufacture labels. Move to a dedicated offline Battle data-generator
design/feasibility task using simulator-only explicit state/action expansion,
pruning/retention and no human/CombatSolver labels.

### `INTERNAL_TELEMETRY_SEMANTIC_PARITY_INVALID`

Enabling telemetry changes any frozen Search/controller output or formal root
reproduction fails.

Consequence: no internal-surface science claim is valid. A successor may repair
telemetry only if the repair remains a bounded read-only instrumentation change;
otherwise abandon this route in favor of a dedicated offline data generator.

### `INTERNAL_SEARCH_INFORMATION_BOUNDARY_INVALID`

Hidden/private simulator data enter exported student-visible content, or
teacher-searchable/public-excluded action-space provenance cannot be separated
reliably.

### `INCOMPLETE`

Required native/source/restore/root/artifact/canary/formal evidence is missing or
invalid.

## Scientific Interpretation Boundary

A positive T092 result means only:

> Frozen Search-v2@400 already visits enough stable **depth>=1 internal** public
> decision states, with enough Search-supported action comparisons, to justify
> testing whether a public student can learn from this larger self-generated
> surface beyond the already-counted root-only evidence.

It does not mean the student is learnable, that internal means are unbiased Q
values, that a student improves Search, that complete runs improve, or that the
privileged teacher is normal-information optimal.

A negative T092 result means only:

> Even after harvesting stable depth>=1 internal Search tree states, the current
> frozen Search process remains an inefficient or biased data source under the
> preregistered comparable-support definition.

That negative result would justify moving to a dedicated training-oriented
offline Battle data generator rather than repeatedly weakening Search-derived
coverage gates.
